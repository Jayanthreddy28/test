# Multiply Club

A friendly browser multiplication quiz for ages 6–10. Answer 10 random questions using numbers 1–10, earn 10 points per correct answer, and see your final score. No timer or installation needed.

Open `index.html` in a browser. For local development, run `python3 -m http.server 8000` from this directory.

Built with plain HTML, CSS, and JavaScript. Google Fonts are optional; system fonts work offline.
